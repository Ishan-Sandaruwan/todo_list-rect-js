# Todo List (React.js)

A simple **Todo List** application built with **React.js**.  
This project demonstrates the fundamentals of React, including state management, props, and component-based architecture.

---

## 🚀 Features
- ➕ Add new todos  
- ✅ Mark todos as completed  
- 🗑️ Delete todos  
- 🎨 Clean and responsive UI  
- ⚡ Built with React for fast rendering  

---

## 🛠️ Requirements
- [Node.js](https://nodejs.org/) (>= 14.x recommended)  
- npm or yarn  

## ▶️ Run Locally

### 1. Clone repository
```
git clone https://github.com/your-username/todo_list-react-js.git
cd todo_list-react-js
```
2. Install dependencies
```
npm install
```
3. Start development server
```
npm start
```
Server will run at http://localhost:3000

🏗️ Build for Production
```
npm run build
```
The optimized production build will be in the build/ folder.
